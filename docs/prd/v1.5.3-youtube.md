# PRD v1.5.3: Anúncios do YouTube

> Base: 1.3.7 (login do Google resolvido). Será publicada como **1.3.8**.
> Origem: teste real da 1.3.7: anúncio em vídeo ("Patrocinado · 1 de 2") e cartões
> patrocinados no YouTube, mesmo com as listas oficiais do uBlock Origin.

## 1. Causa

Reproduzido no app com as **regras e o código reais do uBO para o YouTube**, apontados para
uma página local que imita o player (`ytInitialPlayerResponse` no HTML, `/youtubei/v1/player`
por `fetch` e por XHR): **nenhum** anúncio era removido.

- Os scriptlets eram juntados num único script. Vários trazem a mesma dependência declarada
  como classe (`class JSONPath`, usada pelos `trusted-json-edit-*`); no mesmo escopo a segunda
  declaração é `SyntaxError: Identifier 'JSONPath' has already been declared` e **o script
  inteiro não rodava** — nenhum dos 30 scriptlets do YouTube. Vale para o preload da 1.3.6 e
  para o CDP da 1.3.7.
- Rodados um a um, os mesmos scriptlets removiam `adPlacements`/`adSlots` normalmente.

## 2. Correções

| Item                          | Correção                                                                                                                                                                                                                                                                                                                 |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Scriptlets isolados entre si  | Cada scriptlet no próprio escopo (`(function(){…})()`) e `try/catch`: um erro não derruba os outros e nada fica global (`scriptletGlobals`)                                                                                                                                                                              |
| Mundo de execução do uBO      | Os scriptlets que o uBO roda no mundo isolado (`replace-node-text`, `remove-node-text`… 22 no total, 2 deles no YouTube) vão para um mundo isolado (`worldName` no CDP); os demais, para o mundo da página                                                                                                               |
| Primeira carga numa guia nova | Guia que ainda não navegou e vai para um site com scriptlets (ex.: YouTube numa guia nova ou ao restaurar a sessão) passa antes por `about:blank`; o registro é confirmado e só então o site carrega. O `about:blank` sai do histórico. Numa SPA como o YouTube, perder a 1ª carga deixava a sessão inteira com anúncios |

## 3. Resultados

| Verificação                                                                  | Resultado                                                                                                                             |
| ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Regras reais do uBO para o YouTube (teste e2e novo, baixa as listas na hora) | `ytInitialPlayerResponse`, `fetch` e XHR do player sem `adPlacements`/`adSlots` já na 1ª carga de uma guia nova e na recarga (5 de 5) |
| Scriptlet antes dos scripts da página na 1ª carga                            | 8 de 8 (antes 8 de 10)                                                                                                                |
| Trusted Types (como o YouTube)                                               | Scriptlet do mundo isolado reescreve script inline antes de ele rodar                                                                 |
| `bun run test` / e2e web / e2e desktop                                       | 131 / 21 / 19                                                                                                                         |

## 4. Limites

- Não há acesso ao YouTube neste ambiente de testes; a validação usa as regras e o código reais
  do uBO contra uma imitação do player. O YouTube muda o formato dos anúncios com frequência e
  o uBO responde com regras novas; o app renova as listas a cada 24 h.
- As listas e os scriptlets do uBO são GPLv3: o app os baixa em tempo de execução e o teste
  também; nada do uBO é copiado para o repositório.
